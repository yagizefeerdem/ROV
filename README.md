# Underwater prevezeROV — Vision & Control System

## Project Description
This repository contains software developed for a remotely operated underwater vehicle (ROV). The project focused on supporting robotic control and basic visual analysis using foundational computer vision techniques to assist perception tasks.

The system integrates Python and C++ components to process camera input, handle visual features such as geometric shapes and color ranges, and support core control logic for the vehicle. The project was completed collaboratively as part of a multi-member engineering team.

---

## Role & Responsibilities
Worked as part of the software team contributing to vision-related functionality and overall system integration. Responsibilities included:

- Contributing to scripts that analyze camera input using Python  
- Supporting geometric shape detection and color range processing  
- Assisting with integration of vision components into the broader robotic system  
- Collaborating within a team-based engineering workflow  

This work reflects collaborative development rather than individual code ownership.

## Technologies Used
- **Python** — primary scripting for vision-related tasks  
- **OpenCV** — basic image processing and visual feature handling  
- **C++** — supporting modules for system interaction
